# Security Policy

## Scope

This repository is public and contains metadata and documentation only. It holds no
executable code, credentials, or secrets. Security-relevant findings are therefore
limited to issues such as:

- accidental disclosure of private information (local paths, personal tool names,
  internal workflow details, credentials),
- broken links or references that mislead users into unsafe destinations,
- licensing or provenance misstatements.

## Reporting a vulnerability

Please **do not open a public issue** for security-sensitive findings. Instead, report
them privately:

1. GitHub private vulnerability reporting:
   https://github.com/ActiveInferenceInstitute/gen25/security/advisories
2. Alternatively, contact the Active Inference Institute through its website:
   https://www.activeinference.org

Please include the repository name, the affected file(s), and a description of the
issue. You will receive an acknowledgment and, where applicable, credit in the fix.

## Disclosure

We ask that you give maintainers a reasonable window to address the report before any
public disclosure.
